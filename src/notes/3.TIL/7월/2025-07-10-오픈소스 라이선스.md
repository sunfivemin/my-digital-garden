# 📘 2025-07-10 TIL

# 🌍 오픈소스 기여 여정: 개념부터 실습까지 정복하기

## 🧭 들어가며

요즘 개발자라면 누구나 한 번쯤은 오픈소스에 기여하고 싶다는 생각을 해보았을 것이다. 나 역시 마찬가지였다. 하지만 '어떻게 시작하지?'라는 막연함이 늘 앞섰다. 이 블로그는 오픈소스 라이선스의 개념부터 실습까지, 내가 직접 학습한 내용을 토대로 작성한 기록이다. 특히 Airbnb의 `lottie-web` 프로젝트를 직접 포크해보며 배운 점도 함께 정리했다.

---

## 🧪 실습: Airbnb의 `lottie-web` 프로젝트 포크해보기

> 💡 프로젝트 주소: [https://github.com/sunfivemin/lottie-web](https://github.com/sunfivemin/lottie-web)

### 1단계: 포크(Fork)

- Airbnb의 `lottie-web` 저장소를 내 계정으로 복사

### 2단계: 클론(Clone)

```bash
git clone https://github.com/내아이디/lottie-web.git
```

### 3단계: 원격 저장소 설정

```bash
# 원본 저장소 연결 (upstream)
git remote add upstream https://github.com/airbnb/lottie-web.git
```

### 4단계: 수정 작업 → 커밋 → 푸시

```bash
# 브랜치 생성 후 작업
git checkout -b fix/readme-typo
# 커밋 & 푸시
git push origin fix/readme-typo
```

### 5단계: Pull Request 생성

- GitHub에서 `compare & pull request` 클릭 → 수정 내용 설명 후 PR 생성

### 6단계: 리뷰 → 머지(merge)

- 코드 리뷰를 거친 뒤 PR이 승인되면 머지됨 → 기여 완료 🎉

> 🧩 만약 라이선스가 없는 프로젝트라면, 오픈소스 사용/기여가 불가능할 수 있다. 이슈 탭에 "라이선스 제안"을 등록하거나, 저자에게 직접 요청해보는 것도 하나의 방법이다.

## 🧠 컨트리뷰터 유형과 기여 방법

|유형|예시|
|---|---|
|버그 수정|코드 오류 고치기|
|문서 보완|README 수정, 예제 추가|
|기능 제안|신규 기능 아이디어 제안|
|테스트 추가|테스트 케이스 보완|
|번역|다국어 번역, 오탈자 수정|

### 왜 컨트리뷰션을 하나요?

- 멋진 개발자들과 협업 경험
- 코드 품질 개선에 도움
- 오픈소스 코드 분석 역량 향상
- 포트폴리오로 활용 가능
- 기술 커뮤니티에서의 존재감 확보

## 🔐 오픈소스 라이선스 제안과 변경

- 오픈소스는 중간에 라이선스를 바꿀 수도 있다 (단, 기존 기여자의 동의가 필요)
- 예: MongoDB → AGPL → SSPL (더 강력한 공개 조항 도입)

### 만약 라이선스가 없다면?

- 오픈소스가 아님 = 기여 권한 X
- 사용하고 싶다면, 제안 또는 이슈로 **라이선스 추가 요청** 가능
- GitHub Issue나 Discussions에 "어떤 라이선스를 추가하실 계획이신가요?"와 같은 제안을 남기면 반응이 오는 경우도 많다.

> ✨ [codetriage.com](https://www.codetriage.com/) 같은 플랫폼을 활용하면 나에게 맞는 오픈소스 프로젝트를 손쉽게 탐색하고 기여할 수 있다.

## 🔧 실무에 lottie-web 적용하기

> Lottie는 After Effects로 제작된 JSON 기반 애니메이션을 웹에서 렌더링할 수 있게 해주는 강력한 도구다.

### React에서 사용하는 방법 예시:

```tsx
import { Player } from '@lottiefiles/react-lottie-player';

<Player
  autoplay
  loop
  src="/animations/loading.json"
  style={{ height: '200px', width: '200px' }}
/>
```

- `lottie-react`, `react-lottie-player`, `lottie-web` 중 목적에 맞는 패키지를 선택해 사용 가능
- 로그인, 로딩 화면, 성공 메시지 등에 자연스러운 애니메이션 연출 가능

## 🎯 마무리하며

처음엔 막막했던 오픈소스 기여. 하지만 작은 오타 수정, 문서 개선부터 시작해보면 생각보다 진입장벽이 낮다. 특히 `lottie-web` 같은 유명 오픈소스는 커뮤니티도 잘 구성되어 있어 실습용으로도 아주 좋다. 앞으로도 꾸준히 기여하고, 배운 내용을 나누는 개발자가 되고 싶다.
